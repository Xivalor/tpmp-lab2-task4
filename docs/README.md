# tpmp-lab2-task3

## Overview
Программа для обработки данных о рабочих предприятия. Реализует создание текстового файла с данными, просмотр содержимого, чтение и обработку данных в соответствии с заданием: вывод информации о рабочих, поступивших на работу в 2020 году.

Структура записи:
- Фамилия, имя, отчество
- Домашний адрес (почтовый индекс, страна, область, район, город, улица, дом, квартира)
- Национальность
- Дата рождения (год, месяц, число)
- № цеха
- Табельный номер
- Образование
- Год поступления на работу

## Usage
1. Сборка программы: `make`
2. Запуск: `./worker_program`
3. Интерактивное меню:
   - 1: Создать файл с данными
   - 2: Просмотреть содержимое файла
   - 3: Обработать данные (найти рабочих 2020 года)
   - 4: Просмотреть результат обработки
   - 0: Выход
4. Очистка: `make clean`

## Additional Notes
- Программа написана на C
- Использует модульную структуру (модель КИС)
- Заголовочные файлы в папке `include/`
- Исходный код в папке `src/`
- Данные хранятся в папке `data/`
- Тесты и отчет в папке `docs/`
- GitHub Actions автоматически собирает проект при каждом push
- Программа обрабатывает некорректные строки, пропуская их
- При отсутствии рабочих 2020 года выводится соответствующее сообщение

# tpmp-lab2-task4

## Overview
Программа для обработки данных о рабочих. Читает данные из файла, выводит всех рабочих и фильтрует по году поступления на работу.

Структура данных:
- Фамилия, имя, отчество
- Домашний адрес (индекс, страна, область, район, город, улица, дом, квартира)
- Национальность
- Дата рождения (год, месяц, день)
- № цеха, табельный номер, образование, год поступления

## Usage
1. Создать файл с данными `data/input.txt` (формат: все поля через пробел)
2. Сборка: `make`
3. Запуск: `make run` или `./program`
4. Результат сохраняется в `data/output.txt`
5. Очистка: `make clean`
